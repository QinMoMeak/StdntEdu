# AI错题导入详细设计
流程：上传 → 异步任务 → 文件校验 → 保存原图 → 预处理 → 视觉模型/OCR → JSON Schema校验 → 枚举和知识点校验 → 临时结果 → 人工确认 → 事务写入正式错题。

表：ai_extraction_task、ai_extraction_file、ai_extraction_question、ai_extraction_question_knowledge、ai_extraction_correction。

状态：PENDING、RUNNING、REVIEW_REQUIRED、SUCCESS、FAILED、CANCELLED、EXPIRED。

支持JPG、JPEG、PNG、WEBP和PDF。建议图片15MB、PDF50MB、单任务20张图。

AI输出至少包含document、questions和warnings。看不清内容必须为null，不得编造。

确认页支持修改全部字段、置信度提示、知识点确认、主要知识点、忽略、拆分、合并、排序和切换模型重试。

Token优化：图片只识别一次；保存OCR文本和JSON；不发送完整知识树；只发送候选知识点；后续分析不重复发图片。
