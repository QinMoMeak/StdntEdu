# 页面详细设计
## Dashboard
今日学习、任务、待复习、待看资源、最近成绩、趋势、薄弱知识点、错误类型和AI建议。

## 学生档案
基础资料、当前学期和成长时间轴。

## 成绩
列表筛选；新增考试和动态多学科成绩；详情显示知识点得分与趋势；移动端使用卡片。

## 错题
列表支持PRACTICE/EXAM、学科、知识点、题型、错误类型和状态筛选。新增页支持Markdown、LaTeX、多个知识点、主要知识点和附件。

## 复习
先隐藏答案，作答后显示答案，再选择CORRECT、PARTIAL、WRONG或UNKNOWN。

## AI确认页
桌面端左图右表单，移动端上图下表单；显示置信度、警告；支持编辑、忽略、拆分、合并、排序和确认。

## 资源
WAITING、LEARNING、COMPLETED、REVIEW、ARCHIVED页签；显示来源、时长、进度和知识点。

## 知识树
左树右详情；支持新增、编辑、移动、停用和关联统计。
