# 前端设计
技术：Vue3、TypeScript strict、Vite、Pinia、Vue Router、Axios、Element Plus、ECharts、Vitest。

主要路由：
/dashboard、/student/profile、/scores、/wrong-questions、/reviews、/resources、/knowledge、/ai/analyses、/study-plans、/reports、/data/import、/data/export、/backups、/settings。

要求：
- API层、类型和页面分离
- 禁止大量any
- 所有列表有加载、空和错误状态
- 桌面端表格在移动端改为卡片
- AI识别必须有人工确认页
