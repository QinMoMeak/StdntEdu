# 产品需求 PRD
## Dashboard
今日学习、待复习错题、待看资源、最近成绩、趋势图、薄弱知识点、错误类型分布和AI建议。

## 学生档案
姓名、头像、出生日期、学校、学段、年级、学期、备注和成长时间轴。

## 成绩
支持手动录入、CSV导入和后续AI识别；保存考试名称、类型、日期、多科成绩、满分、排名和知识点得分。

## 错题
来源一级分类固定为PRACTICE和EXAM。保存题目、学生答案、正确答案、解析、题型、错误类型、难度、知识点、图片、状态和复习信息。

## 学习资源
支持Bilibili、网盘、本地文件、PDF和网页；保存知识点、进度、历史和笔记。

## AI
支持OCR、题目拆分、结构化识别、知识点匹配、成绩分析、错题分析、计划与报告。AI不得未经确认写入核心数据。

## 数据管理
支持CSV、Excel、JSON、Markdown、PDF和ZIP导出；支持数据库、附件和完整备份恢复。
