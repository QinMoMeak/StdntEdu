# V3 阶段零复查
只读检查，不修改文件。

1. 用 OpenAPI 校验器检查 `api/openapi.yaml`。
2. 检查所有路径变量均有 required path parameter。
3. 检查主要 POST/PUT 均有 requestBody。
4. 检查成功响应绑定 Schema。
5. 检查附件、AI识别和导入使用 multipart/form-data。
6. 检查字典初始化包含错误类型、题型、成长事件和资源来源。
7. 检查 Flyway 为 V1 至 V13。
8. 检查核心状态 CHECK。
9. 检查 REVIEW_REQUIRED 与 PENDING_REVIEW 的区分。
10. 按阻塞开发、重要、可延后输出，完成后停止。
