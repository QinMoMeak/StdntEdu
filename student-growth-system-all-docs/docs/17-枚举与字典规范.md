# 枚举与字典规范
数据库保存英文大写编码，前端显示中文。

学段：PRIMARY、JUNIOR、SENIOR。
学期：FIRST、SECOND、SUMMER、WINTER、OTHER。
错题来源：PRACTICE、EXAM。
错题状态：NEW、REVIEWING、MASTERED、ARCHIVED。
复习结果：CORRECT、PARTIAL、WRONG、UNKNOWN。
资源状态：WAITING、LEARNING、COMPLETED、REVIEW、ARCHIVED；禁止使用旧编码DONE。
AI状态：PENDING、RUNNING、REVIEW_REQUIRED、SUCCESS、FAILED、CANCELLED、EXPIRED。
计划状态：DRAFT、ACTIVE、PAUSED、COMPLETED、CANCELLED、EXPIRED。

错误类型默认：KNOWLEDGE_GAP、CONCEPT_CONFUSION、FORMULA_ERROR、CALCULATION_ERROR、READING_ERROR、METHOD_ERROR、UNIT_ERROR、CARELESS、UNKNOWN、OTHER。

动态字典：错误类型、题型、成长事件类型、资源来源和自定义标签。
