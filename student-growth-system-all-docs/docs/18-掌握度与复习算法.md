# 掌握度与复习算法
掌握度0至100。等级：0-39未掌握，40-59薄弱，60-79基本掌握，80-94良好，95-100熟练。

初始值：首次正确60、部分正确45、错误30、不会20。

基础变化：考试正确+10、部分+4、错误-12；练习正确+6、部分+2、错误-8；复习正确+8、部分+3、错误-10、不会-14。

难度系数：1=0.8、2=0.9、3=1、4=1.1、5=1.2。

公式：
newScore = oldScore + baseChange × difficultyFactor × confidence × knowledgeWeight + streakAdjustment。

主要知识点权重0.6，其余平均分配0.4。单次最大上升15、下降20；每日同知识点上升20、下降25。

复习阶段间隔：1、3、7、15、30、60、120天。正确阶段+1；部分不变且间隔减半；错误阶段-1并1天后复习；不会归0。

必须保存mastery_history。人工可调整和锁定。AI不得直接修改掌握度。
